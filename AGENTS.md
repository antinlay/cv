# AGENTS.md

## Кратко о проекте
- Это Swift Package со статическим сайтом на Ignite.
- Точка входа: `Sources/Site.swift`.
- Сайт публикуется в `Build/`, деплой на GitHub Pages описан в `.github/workflows/deploy.yml`.

## Где что менять
- `Sources/Content/SiteContent.swift` — весь контент, локализация, ссылки, данные резюме.
- `Sources/Pages/*.swift` — страницы и их маршруты.
- `Sources/Components/*.swift` — секции, контролы и переиспользуемые блоки.
- `Sources/Layouts/MainLayout.swift` — общий layout, head, общие стили/подключения.
- `Assets/` — статические ассеты.

## Правила для правок
- Сначала найди точный файл и меняй минимально.
- Не редактируй `Build/`, `.build/`, `.swiftpm/` вручную — это артефакты.
- Учитывай GitHub Pages base path: `SitePaths.base == "/cv"`.
- Если меняешь URL, ассеты или генерацию HTML, проверь логику post-process в `Sources/Site.swift`.
- Держи `ru/en` и `short/full` варианты синхронными по структуре и смыслу.
- При добавлении новой страницы не забудь зарегистрировать ее в `PortfolioSite`.

## Проверка после изменений
- Базовая проверка для Swift-кода: `swift build`
- Если менялся контент, страницы, layout или ассеты сайта: `swift run`
- Если менялись зависимости: `swift package resolve`

## Ответ в финале
- Всегда указывай: что изменено и где.
- Всегда давай команду проверки.
- Риски и краевые кейсы указывай только если они реально есть.
